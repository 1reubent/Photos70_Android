# How GenAI Was Used in This Project

## Prompts Issued

All GenAI usage in this project was through the GitHub Copilot extension in Android Studio, using both the inline suggestions and the Copilot chat.

### Layouts

Most UI layouts were generated by AI. I provided guidance or requested refinements when necessary to achieve the desired result.

### `Home.java`

- Used AI to configure list selection using XML attributes such as `android:background`, `android:listSelector`, `and android:choiceMode`.

- For the button listeners (of all classes), I generally allowed Copilot to generate the initial logic, which I then refined manually.

- AI generated the `AlbumAdapter.java` to handle album list display.
 
- Used AI help in organizing album management logic, which led to the creation of DataManager.java to handle saving/loading and updating albums on disk.
 
- For the *create album* button listener, AI assisted with writing the syntax for a dialog.

### `AlbumViewActivty.java`

- For the *add photo* button listener, AI helped with loading photos into the app’s internal storage. I implemented a `getRealPathFromURI()` method to copy the image into internal storage (`getFilesDir()`) due to Android’s scoped storage restrictions.

- For the *move photo* button listener, AI assisted in writing the dialog syntax.

### `DisplayPhotoActivity.java`

- Used AI to help structure and organize the logic for displaying a photo and its associated metadata.

### `SearchPhotosActivity.java`

- Used AI to implement logic for autocompleting search results
